# Web Application

**Status: SKELETON.** This Vite + React + TypeScript application is reserved for the feature-oriented teacher and student interface.

## Current implementation

The repository contains the feature directory structure, minimal app shell and a component test. No authenticated UI, API client, routing tree, Tailwind setup, shadcn/ui components, TanStack Query integration or Zustand store has been implemented.

## Planned scope

Features are organized as auth, project, backlog, sprint, task, kanban, classroom, github, ai and notification. Server state belongs to TanStack Query; UI/client state belongs to Zustand.

## Not implemented

All product screens and user workflows, login, project/task operations, GitHub connection, AI approval review, design system, drag-and-drop and E2E tests remain TODO.
